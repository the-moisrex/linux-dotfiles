# pkgs/pacman-core.txt mapped to distro package names.
# columns:  <arch>  <debian/ubuntu>  <fedora>
#
# Consumers: pods/recipes/dotfiles (image build) and setup/install-packages.sh
# (apt hosts). col1 is looked up for every pacman-core package; the recipe
# dies when an entry is missing, keep the files in sync.
#
#   NONE   placeholder: not packaged there -- consumers report it as
#          skipped instead of silently dropping it
#   $name  special entry: not a repo package at all (manual install)
#
# Names verified against Debian trixie, Ubuntu resolute and Fedora 44
# repository metadata; trailing comments carry pacman-core's reasons.
